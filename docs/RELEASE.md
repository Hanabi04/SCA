# Release notes

## Initial release

Includes SCA selection and inference code, task baselines, seven SLURP prediction groups, evaluation manifests, and numeric deduplication classifiers. `python reproduce.py` recomputes the bundled results and exports Excel and CSV tables.

FSC sample-level records and raw speech are not distributed. Local FSC inference is described in [INFERENCE.md](INFERENCE.md); data and model terms are listed in [../NOTICE.md](../NOTICE.md).
